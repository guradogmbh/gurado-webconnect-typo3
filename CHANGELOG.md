# Changelog

## 1.0.0 - Initial public release (pending publication)

- Integrate the gurado WebConnect gift voucher shop into TYPO3 13.4 and 14.
- Embed Mode content element: Articles, Categories and Single Article with optional Article ID.
- Site-wide Bubble Mode through TYPO3 Site Settings with Default, Articles and Article starting views; position and offset settings.
- Configure the existing gurado shop using its Storecode.
- English and German backend labels and official gurado branding.
- Complete TYPO3 documentation including installation, dashboard setup, redemption and reporting information, and nine screenshots.
- Free gurado plan and free TYPO3 integration documented; 10 redemptions per 30-day period on the Free plan.
- GitHub Actions for PHP lint, composer checks, XML, documentation images and dependency resolution on TYPO3 13.4 / 14.3.

**Verification:** Basic functional testing confirmed by the project on TYPO3 14.3.9. CI dependency resolution for TYPO3 13.4 and 14.3 passed. No full TYPO3 13.4 runtime integration test has been reported.
